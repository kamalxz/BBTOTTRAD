# 🎯 بوت السكالبر - استراتيجية القناص المتوازن

## نظرة عامة
بوت تداول تلقائي متخصص في استراتيجية Scalping عالية الدقة، مصمم للعمل فقط مع **القائمة الذهبية** من العملات التي أثبتت كفاءة تفوق 90%.

## ✨ المميزات
- **11 فلتر أمان** لضمان دخول صفقات عالية الجودة فقط
- **نسبة فوز مستهدفة**: 90%+
- **متعدد الفريمات**: يستخدم فريم 15 دقيقة للاتجاه وفريم 1 دقيقة للدخول
- **فلتر أخبار سلبي**: يتجنب التداول عند وجود أخبار سلبية
- **إدارة مخاطر متقدمة**: Trailing Stop ديناميكي

## 📁 هيكلية المشروع
```
/workspace/
├── config.py              # الإعدادات والثوابت
├── main.py                # نقطة الانطلاق
├── requirements.txt       # المكتبات المطلوبة
├── .env.example           # مثال لملف المفاتيح
├── core/
│   ├── exchange_manager.py  # الاتصال بـ Binance
│   └── news_agent.py        # وكيل الأخبار
├── modes/
│   └── scalper.py           # استراتيجية السكالبر
└── utils/
    └── logger.py            # التسجيل (قيد التطوير)
```

## 🔧 التثبيت

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. إعداد المفاتيح
انسخ ملف `.env.example` إلى `.env` واملأ مفاتيحك:
```bash
cp .env.example .env
```

ثم عدل ملف `.env`:
```
BINANCE_API_KEY=your_key_here
BINANCE_SECRET_KEY=your_secret_here
```

## 🚀 التشغيل

### وضع المحاكاة (مفعل افتراضياً)
```bash
python main.py
```

### للتداول الحقيقي
عدّل `config.py` وغير `PAPER_TRADING = False`

## 🛡️ الفلاتر الـ 11
1. نوع العملة (القائمة الذهبية فقط)
2. الأخبار السلبية
3. الاتجاه العام (EMA 200)
4. الزخم (ADX > 28)
5. التشبع السعري (RSI)
6. حجم التداول (Volume Spike)
7. الارتداد الديناميكي (EMA 50)
8. ترتيب المتوسطات (EMA 20/50)
9. وقت الجلسة (لندن/نيويورك)
10. نسبة العائد للمخاطرة
11. الانزلاق والفروقات

## ⚙️ الإعدادات الافتراضية
- **فريم الدخول**: 1 دقيقة
- **فريم الاتجاه**: 15 دقيقة
- **Stop Loss**: 0.7 x ATR
- **Take Profit**: 0.5 x ATR
- **Trailing Stop**: يُفعّل عند 0.3% ربح

## 📝 ملاحظات هامة
- البوت في وضع المحاكاة افتراضياً لأغراض الاختبار
- نسبة الفوز العالية تأتي على حساب قلة عدد الصفقات (5-10 يومياً)
- يُفضل التشغيل خلال جلسات لندن ونيويورك لزيادة السيولة
